# homebrew-tap

[Homebrew](https://brew.sh) tap of [EdrenaVosh](https://github.com/EdrenaVosh).

## squad-up

[squad-up](https://github.com/EdrenaVosh/squad-up) switches Claude Code agent teams with one command and always gives your original setup back.

```sh
brew install EdrenaVosh/tap/squad-up
```

This installs two names for the same program: `squad` and `squad-up`. Update with `brew upgrade EdrenaVosh/tap/squad-up`.

## About this repository

The files in `Casks/` are generated and pushed here by the release workflow of [squad-up](https://github.com/EdrenaVosh/squad-up) (GoReleaser) when a version is released. Do not edit them by hand: the next release overwrites them.

Report problems with the tool or its installation in the [squad-up issues](https://github.com/EdrenaVosh/squad-up/issues).
